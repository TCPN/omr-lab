# Agent Task Prompt

Read AGENTS.md, architecture and schema docs, then the assigned GitHub Issue before changing code. First summarize the plan and any conflicts/blockers. Implement the smallest complete change within issue scope, add/update tests, and run required checks.

Do not claim commands passed unless executed. Do not fabricate engine availability or recognition quality. If an external prerequisite is missing, report the exact check and mark that verification as not run.

At completion report: (1) summary, (2) files changed, (3) commands and actual results, (4) acceptance criteria met/not met, (5) tests not run and why, (6) risks and follow-up issue.
