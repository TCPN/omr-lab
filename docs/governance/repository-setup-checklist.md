# Remote Repository Setup Checklist

This scaffold is intended to be applied to the existing omr-lab repository.
1. Confirm Actions are enabled.
2. Create labels and milestones listed in milestones-and-labels.md.
3. Create issues from docs/issues/OMR-*.md in dependency order.
4. Record actual issue numbers/URLs in docs/issues/README.md.
5. Enable branch protection for main where available: PR + CI checks required.
6. Add a Project board later only if it improves workflow.

Suggested description: Local-first, modular Optical Music Recognition pipeline with reproducible engine benchmarks.
